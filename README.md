# Análisis de Datos Para la Optimización de  Variables Ambientales En Sistemas de Microclimas Controlados a través de Internet of Things (IoT) 

Este proyecto presenta un análisis exhaustivo de datos recolectados de invernaderos automatizados, con el objetivo de evaluar y mejorar las condiciones ambientales y su impacto en la producción agrícola. Inicialmente, se realizó un **Análisis Exploratorio de Datos (EDA)** para comprender la distribución de las variables, identificar patrones y detectar posibles anomalías. Se generaron histogramas, gráficos de barras y matrices de dispersión, además de matrices de correlación para evaluar relaciones entre variables climáticas y de producción. Posteriormente, se implementó un **análisis de series temporales** sobre variables clave, aplicando descomposición en componentes de tendencia, estacionalidad y residuales, junto con técnicas de modelado predictivo utilizando modelos ARIMA. La precisión de las predicciones se evaluó mediante métricas como **MAE (0.7575)** y **RMSE (0.8926)**. Este enfoque permite comprender mejor las dinámicas ambientales dentro del invernadero y proporciona una base para la optimización de procesos y la toma de decisiones en sistemas agrícolas automatizados.
